# Soil Sense — ชุดวัดดินสองระดับและฝน

ไฟล์ใช้งานล่าสุด: `Soil-Sense-Complete.ckt` เปิดผ่าน Cirkit Designer → File → Import → Import Local Cirkit File → Open As New File

## สิ่งที่วัด

| ตำแหน่ง | อุปกรณ์ที่ใช้จริง | ข้อมูล | การเชื่อมต่อ |
| --- | --- | --- | --- |
| ดินระดับ 1 | DFRobot SEN0604 หรือหัววัด RS485 ที่มีสเปกเทียบเท่าและตรวจคู่มือรุ่นจริง | ความชื้น อุณหภูมิดิน pH และ EC | MAX485 → Serial1 ของ UNO R4 |
| ดินระดับ 2 | DFRobot SEN0308 แบบ capacitive วัดความชื้นโดยเฉพาะ | สัญญาณความชื้นอีกระดับหนึ่ง | Analog A0 |
| เหนือดินในพื้นที่เปิด | เครื่องวัดฝนแบบ tipping bucket ชนิด reed contact 2 สาย เช่น SparkFun Rain Gauge | จำนวนการกระดก → ปริมาณฝนตาม mm/tip ของรุ่น | Digital D3 |

มีเซ็นเซอร์ 3 ตัวและข้อมูล 6 ช่อง: ความชื้น 2 ระดับ อุณหภูมิดิน pH EC และปริมาณฝน ประวัติย้อนหลังได้จากการอ่านพร้อมเวลาและบันทึกในระบบ ไม่ต้องใช้เซ็นเซอร์ประวัติแยก

แบบนี้เปลี่ยนหัววัดระดับ 2 จาก RS485 ที่ใช้ภาพ 4-in-1 ซ้ำ เป็น capacitive analog ที่หน้าตาแตกต่างกันแล้ว จึงไม่มีหัววัด RS485 ตัวที่สองและไม่ต้องตั้ง Modbus ID 2

## รายการอุปกรณ์

- Arduino UNO R4 WiFi 1 บอร์ด
- หัววัด RS485 4-in-1 ดิน 1 ตัว (อ้างอิง SEN0604)
- โมดูล UART ↔ RS485 ชนิด MAX485 ที่ทำงานกับ logic 5V 1 ตัว
- หัววัดความชื้นดิน capacitive แบบกันน้ำ SEN0308 1 ตัว
- เครื่องวัดฝนแบบกระดกหน้าสัมผัส reed switch แห้ง ปกติเปิด 2 สาย 1 ตัว
- แหล่งจ่าย regulated 12V สำหรับหัววัด RS485 และ USB 5V สำหรับบอร์ด
- ขั้วต่อ สายสัญญาณ กล่องกันสภาพอากาศ และ cable gland สำหรับติดตั้งภายนอก

ภาพ SEN0604 ในไฟล์เป็นรูปหัววัด 4-in-1 อ้างอิงจากคลัง ไม่ใช่หลักฐานยืนยันรุ่นตรงกัน ภาพ capacitive เป็น DFRobot V1.0 สำหรับแสดงการต่อ analog; รายการจัดซื้อภายนอกเลือก SEN0308 แบบกันน้ำ ภาพเครื่องวัดฝนเป็นภาพประกอบรูปทรงจากคลัง โดยสร้างสัญลักษณ์ 2 ขั้วใหม่สำหรับ **รุ่น passive dry-contact เท่านั้น** ไม่ใช่ pinout ของเครื่องวัดฝน powered 3 สายที่อาจมีหน้าตาคล้ายกัน

## ตารางสายไฟ

| จาก | ไป |
| --- | --- |
| UNO 5V | MAX485 VCC และ SEN0308 VCC |
| UNO GND | MAX485 GND, SEN0308 GND และลบของแหล่งจ่าย 12V |
| UNO D1 / TX (Serial1) | MAX485 DI |
| UNO D0 / RX (Serial1) | MAX485 RO |
| UNO D2 | MAX485 DE และ RE แบบ active-low |
| MAX485 A | SEN0604 RS485-A |
| MAX485 B | SEN0604 RS485-B |
| 12V บวก | SEN0604 VCC เท่านั้น |
| 12V ลบ | SEN0604 GND และ common ground |
| SEN0308 analog signal | UNO A0 |
| Rain contact 1 | UNO D3 |
| Rain contact 2 | UNO GND |

หัววัด SEN0308 ใช้ 3.3–5.5V ห้ามนำเข้าราง 12V ขั้ว ground ซ้ำในสายรุ่นจริงให้ต่อ ground ตามคู่มือผู้ผลิต ไม่ผูกเข้าขาสัญญาณ

บอร์ด UNO R4 WiFi ใช้ `Serial1` สำหรับ D0/D1 ส่วน `Serial` ใช้ USB debug ได้ บอร์ดและ MAX485 ใช้ logic 5V การเชื่อม Wi-Fi มีในบอร์ด ไม่ต้องเพิ่ม ESP32 อีกบอร์ดในต้นแบบนี้

## การตั้งค่าอ่านข้อมูล

1. หัววัด RS485 ตัวเดียว: ตรวจ Modbus ID (ค่าเริ่มต้น 1), baud/parity และ register map ตามคู่มือรุ่นจริง ใช้ Serial1; D2 ควบคุมทิศทาง MAX485 การเขียน register เพื่อตั้ง ID ไม่ได้เกิดขึ้นจากไฟล์แผนผัง
2. SEN0308: อ่าน A0 เก็บทั้งค่า ADC/แรงดันและผลสอบเทียบ เลือกความละเอียด ADC ให้ตรงกับสเกลที่ใช้ การเทียบแห้ง/เปียกสองจุดเป็นเพียงดัชนีความชื้นสัมพัทธ์ ไม่ใช่เปอร์เซ็นต์ VWC ที่ยืนยันแล้ว หากต้องนำไปคำนวณน้ำจาก FC/WP ต้องสอบเทียบกับตัวอย่างดินและหน่วย VWC ให้ตรงกัน
3. เครื่องวัดฝน passive: ตั้ง D3 เป็น `INPUT_PULLUP`, นับขอบ `FALLING` ด้วย `digitalPinToInterrupt(3)` และกรอง switch bounce ตามรุ่น เก็บตัวนับด้วยชนิดข้อมูลที่เหมาะสม อ่านจาก interrupt อย่างปลอดภัย ใช้ `rain_mm = valid_tips × mm_per_tip` โดย mm/tip มาจากรุ่นจริงและทดสอบด้วยน้ำปริมาตรทราบค่า ไม่ใช้ค่าของคนละรุ่น
4. เก็บเวลาที่อ่าน (`observed_at`), รหัสสถานี/หัววัด, ระดับความลึกจริง (`depth_cm`), ค่าดิบ, หน่วย, สถานะข้อมูล และรุ่นการสอบเทียบ เก็บค่าฝนเป็นผลต่างในช่วงเวลาที่กำหนดพร้อมตัวนับสะสมและการตรวจรีเซ็ต

## ติดตั้งและตรวจต้นแบบ

- เลือกความลึก 2 ระดับให้สอดคล้องพืช ระยะเติบโต และชั้นราก บันทึกค่าจริง ไม่กำหนด 20/40 ซม. เหมารวมทุกพืช
- ให้หัววัดสัมผัสดินแน่น ไม่มีช่องอากาศ ใช้สาย analog สั้นตามสเปกรุ่นและแยกจากสายกำลัง หากหัววัดอยู่ห่างสถานีมาก ให้เปลี่ยนชนิดการส่งสัญญาณหลังทบทวนระยะจริง
- วางเครื่องวัดฝนให้ได้ระดับ อยู่ในที่เปิด และตรวจทางน้ำไม่อุดตัน
- ทดสอบหัววัดแยกทีละตัวก่อนรวม ตรวจแรงดัน 5V/12V, common ground, A/B, CRC/timeout และขั้วสายตามคู่มือจริง
- ทดลองให้ดินแห้ง/เปียก เปรียบเทียบตัวอย่างจริง และทดสอบจำนวนฝนแต่ละกระดกหลัง debounce
- งานภายนอกต้องทบทวนกล่อง ขั้วต่อ การป้องกันไฟกระชาก/ฟ้าผ่า ระบบพลังงาน และสัญญาณเครือข่ายตามพื้นที่จริง ต้นแบบในแผนผังยังใช้ USB + 12V; ยังไม่มีแบบวงจรแบตเตอรี่/โซลาร์หรือ LoRa ที่ผ่านการตรวจ

## ขอบเขตความสามารถ

ชุดนี้ติดตามสภาพดินและช่วยวางแผนน้ำได้ แต่ยังต้องมีชนิดดิน FC/WP ความลึกราก วันปลูก/พันธุ์พืช ฝนพยากรณ์ และ ET0/Kc เพื่อคำนวณคำแนะนำให้น้ำตามพืชอย่างมีหลักฐาน ค่า EC ไม่ใช่การวัด NPK หรือสารเคมีตกค้างโดยตรง และชุดนี้ไม่ประเมินความอุดมสมบูรณ์ทั้งหมดหรือออกผลรับรอง ICS

ยังไม่เพิ่ม NPK ราคาถูกหรือ sensor อากาศซ้ำ เพราะยังไม่มีโจทย์สอบเทียบ/ความจำเป็นที่ชัดเจน ระดับน้ำเพิ่มได้เมื่อมีโจทย์นาน้ำขังหรือถังเก็บน้ำที่ระบุแล้ว

**สิ่งที่ทำเสร็จในงานนี้:** แบบเดินสายและรายการอุปกรณ์ ตรวจโครงข่ายในไฟล์ และตรวจภาพหลังนำเข้า Cirkit Designer

**สิ่งที่ยังไม่อ้างว่าทำแล้ว:** ซื้อ/ต่อฮาร์ดแวร์จริง, สอบเทียบ, รัน simulator เซ็นเซอร์, firmware อ่านข้อมูลครบชุด, เชื่อมข้อมูลใหม่เข้าฐานข้อมูล/dashboard แบบใช้งานจริง การเพิ่มรูปหัววัดในวงจรไม่ทำให้เว็บรับข้อมูล 6 ช่องโดยอัตโนมัติ
