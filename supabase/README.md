# ฐานข้อมูล Soilข่อยแน

`migrations/` เก็บประวัติฐานข้อมูลเดิมครบ เพื่อรองรับฐานข้อมูลที่ติดตั้งอยู่และตาราง `profiles` สำหรับบัญชีเจ้าหน้าที่

- `202610170001_initial_schema.sql` เป็นฐานเดิมที่สร้างบัญชีและสิทธิ์
- `202610200009_soil_monitoring.sql` เพิ่มอุปกรณ์ ค่าที่อ่านได้ การรับข้อมูล และ dashboard Soil
- migration คั่นกลางเป็นประวัติระบบเดิม เก็บไว้เพื่อไม่ให้ประวัติฐานข้อมูลที่ใช้งานอยู่ขาดหาย

สำหรับฐานข้อมูลที่มี migration เดิมแล้ว ให้ตรวจว่าติดตั้ง Soil migration แล้วหรือยัง ก่อนรัน ห้ามรันซ้ำโดยไม่ตรวจสอบ

ผู้ใช้ต้องมี profile ที่ `active = true` และ role `admin`, `manager`, `extension` หรือ `inspector` เพื่ออ่านข้อมูล Soil ผ่าน RLS

รายละเอียดการตั้งค่าและ Gateway อยู่ใน `../docs/soil/README.md`
