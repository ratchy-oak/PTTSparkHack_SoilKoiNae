# Soilข่อยแน

ระบบติดตามสภาพดินบนแผนที่ พร้อมรายละเอียดเซ็นเซอร์ กราฟ และสิทธิ์บัญชีเจ้าหน้าที่

## เริ่มต้น

1. `npm ci`
2. ตั้งค่า `.env.local` ตาม `.env.example`
3. `npm run dev`
4. เปิด http://127.0.0.1:3000 และเข้าสู่ระบบด้วยบัญชีเจ้าหน้าที่

`npm test` ตรวจตรรกะเซ็นเซอร์และสิทธิ์ฐานข้อมูล · `npm run build` ตรวจการ build

รายละเอียดอุปกรณ์ เกณฑ์ทดลอง และการรับข้อมูล: [docs/soil/README.md](docs/soil/README.md)

## โครงสร้าง

- `app/` หน้าเว็บ เข้าสู่ระบบ และ API รับข้อมูล Soil
- `components/soil/` แผนที่ รายละเอียด และการตรวจ session
- `lib/soil/` ข้อมูลเซ็นเซอร์และการประเมิน
- `supabase/migrations/` ประวัติฐานข้อมูล รวม schema เดิมที่เป็นฐานของบัญชีเจ้าหน้าที่
- `tests/soil.test.ts` ทดสอบระบบ Soil
- เอกสาร PDF/ภาพโจทย์ในโฟลเดอร์หลักเป็นข้อมูลอ้างอิงของโครงการ

ข้อมูลตัวอย่างใช้แสดงบนเบราว์เซอร์เท่านั้น การเชื่อมอุปกรณ์จริงต้องติดตั้ง migration Soil และตั้งค่า Gateway ตามเอกสาร
